# 工业网络协议与端口指纹库

> 用途：巡检时依据"端口开放/关闭"反推现场存在哪类工业设备、该协议的典型故障模式是什么。
> 说明：端口号与传输层属性为公开的协议规范事实，可直接用于诊断推理。

## 工业以太网协议端口指纹表

| 协议 | 默认端口 | 传输层 | 常见设备 | 通断含义 |
|---|---|---|---|---|
| Modbus TCP | 502 | TCP | PLC、电表、变频器、网关 | 端口通但读写超时，多为从站站号错或寄存器越界 |
| Siemens S7comm | 102 | TCP | S7-200 SMART / 300 / 1200 / 1500 | 端口通但连接被拒，多为连接资源耗尽或机架槽号配置错 |
| EtherNet/IP | 44818（显式报文）、2222（UDP 隐式 I/O） | TCP / UDP | 罗克韦尔 ControlLogix、AB | 44818 通而 2222 不通，多为 I/O 连接未建立、组播被阻断 |
| OPC UA | 4840 | TCP | 上位机、SCADA、网关 | 端口通但握手失败，多为证书不受信任或安全策略不匹配 |
| MQTT | 1883（明文）、8883（TLS） | TCP | 边缘网关、传感器汇聚 | 频繁掉线多为 KeepAlive 小于网络抖动周期 |
| OPC Classic (DCOM) | 135 + 动态端口 | TCP | 老式 SCADA | 135 通但动态端口段被防火墙拦截，表现为"能连上不能读" |
| DNP3 | 20000 | TCP | 电力、水务 RTU | 链路层复位频繁多为串口转以太网丢帧 |
| IEC 60870-5-104 | 2404 | TCP | 电力调度 | 总召超时多为 APCI 序号不同步 |
| BACnet/IP | 47808 | UDP | 楼宇自控、暖通 | UDP 无连接，只能靠广播发现 |
| Omron FINS | 9600 | TCP/UDP | 欧姆龙 CJ/CP 系列 | 节点号冲突会导致间歇性通讯失败 |
| 三菱 MC 协议 | 5007 | TCP/UDP | 三菱 FX5U / Q 系列 | 多为二进制/ASCII 帧格式选错 |
| HART-IP | 5094 | TCP | 仪表 | 多设备轮询下超时，多为网关并发不足 |
| SNMP | 161 | UDP | 工业交换机、UPS | 采集失败多为团体名/ACL 限制 |
| NTP | 123 | UDP | 全站时钟 | 时间偏差导致事件顺序（SOE）记录错乱 |
| PTP (IEEE 1588) | 319 / 320 | UDP | 运动控制、同步轴 | 抖动大时先查交换机是否支持透明时钟 |
| PROFINET | 无 TCP 端口，EtherType 0x8892 | 二层 | 西门子分布式 I/O | **ping 不通不代表断线**，必须看 DCP/LLDP 与端口状态 |
| EtherCAT | 无 TCP 端口，EtherType 0x88A4 | 二层 | 伺服、运动控制 | 只能通过主站状态机与从站计数判断 |

## 为什么工业现场不能只用 ping 判断通断

PROFINET、EtherCAT、CC-Link IE 等实时工业以太网工作在二层，不经过 IP 栈：

1. 设备可能完全不响应 ICMP，ping 必然显示 100% 丢包，但产线仍在正常生产。
2. 反过来，ping 能通只说明 IP 栈可达，不代表实时数据通道正常。
3. 因此判断逻辑必须是：**先用 ICMP/端口做初筛，再用协议层状态（主站诊断、从站在线数、丢帧计数）做确认**，两层结论冲突时以协议层为准。

## 工业网络的四层定位模型

巡检结论必须能落到某一层，否则无法指导处置：

- **L1 物理层**：网线、水晶头、光模块、供电、接地、屏蔽。特征：整段丢包、误码率高、链路频繁 up/down。
- **L2 链路层**：交换机端口状态、VLAN 划分、环网冗余、STP、MAC 表漂移。特征：同交换机下多台设备同时异常，跨交换机正常。
- **L3 网络层**：IP 冲突、网关、路由、子网掩码、NAT。特征：同网段内互通，跨网段不通。
- **L4 应用/协议层**：端口、连接数、站号、寄存器地址、证书、KeepAlive。特征：能 ping 通、端口通，但业务读写失败。

## 工业现场常见的时间与并发约束

1. **连接资源上限**：S7-1200 一类小型 PLC 的并发连接数有限（通常个位数到十几），上位机、触摸屏、巡检工具同时连接会把资源占满，表现为"新连接一律被拒、老连接正常"。巡检工具本身也会抢占连接。
2. **轮询周期**：Modbus 从站在被高频轮询时响应会退化，巡检不应以高于生产采集的频率访问同一从站。
3. **安全边界**：巡检工具属于生产网内的主动探测行为，必须遵守"只读、低频、不改写"的原则，禁止对 PLC 写寄存器。
